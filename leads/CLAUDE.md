# Leads folder rules

These rules apply to this folder only.

- Everyone in this folder is a made-up practice person. None of them is real.
- Never add real people or real email addresses.
- Every row needs a consent value. Do not add a row with an empty `consent` column.
- Never change the `@example.com` addresses. That domain is reserved and can never receive mail, so no real person is ever emailed.
